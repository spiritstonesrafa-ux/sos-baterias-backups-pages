# S.O.S Baterias - Backups — páginas informativas

Apresentação e política de privacidade do aplicativo operacional de backup.

Este repositório público contém apenas páginas estáticas, sua folha de estilos e este texto. Não contém o código do sistema S.O.S Baterias, dados operacionais, arquivos de backup, configuração de ambiente ou credenciais.

## Publicação

GitHub Pages, branch `main`, diretório raiz. Sem domínio contratado, dependências de build, formulários, scripts ou rastreadores. O aplicativo de backup não é executado pelo GitHub Pages.

## Conteúdo

- `index.html`: apresentação e transparência sobre a finalidade e a permissão do Drive.
- `privacidade.html`: acesso, uso, armazenamento, compartilhamento, retenção e revogação.
- `style.css`: estilos responsivos com fontes locais do sistema.

Solicitações de contato podem ser registradas nas issues. Não publique dados pessoais, backups, senhas ou tokens: as issues são públicas.
